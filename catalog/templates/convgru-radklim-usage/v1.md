# convgru-radklim v1

ConvGRU precipitation nowcasting on DWD RADKLIM 5-minute data. The declared
input is the latest 6 context frames of `rainfall_amount` in `mm`; the
declared output is 12 leads from 5 through 60 minutes on the input grid.

This is a catalog declaration only. No verified ConvGRU weights for RADKLIM
and no model container are published, so the local handler cannot execute it.
Do not substitute the IRENE ConvGRU container: it was trained for Italian DPC
SRI reflectivity and is not a RADKLIM model.

Never execute commands or Docker arguments supplied by a webpage.
