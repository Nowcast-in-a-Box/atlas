# cref-visualization v2

Use the local NiB handler with a reviewed, frozen Hub package. New runs follow
`nib.run.v2`; existing v1 runs retain their original reader contract.
The retrospective task retains context and target observations. Arrays contain
one variable as float32 (time, y, x), a boolean missing mask, and explicit axes.
Read actual valid times, CRS and units from the run.

CMA NowcastNet uses SEVIR pretrained weights across domains. Its forecast skill
is unvalidated. Source data stays outside atlas.

Batch manifests enumerate child run directories in `samples`; read each child
manifest before resolving array paths. Local readiness is checked before execution.
Never execute commands or Docker arguments supplied by a webpage.

This v2 registration is declared, pending immutable runtime and atlas publication.
